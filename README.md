# Лабораторна робота № 1

**Тема:** Розгортання середовища автоматизації тестування. Структура проєкту та перший автоматизований тест.

**Виконавець:** Заплетнюк Євгеній Сергійович. **Група:** 3 ІПЗ.

## Встановлення й запуск

Потрібен Node.js 24.21.0 або сумісна новіша версія. Команди виконуються в каталозі `Code`.

```sh
npm ci
npm test
npm run test:watch
npm run coverage
npm run lint
npm run typecheck
npm run format:check
```

`test:watch` працює до зупинки через `Ctrl+C`. HTML-звіт покриття: `coverage/index.html`.
Для автоматичного форматування: `npm run format`.

## Структура

- `src/temperature.ts` — показовий модуль перетворення температури.
- `tests/temperature.test.ts` — тести показового модуля.
- `vitest.config.ts` — середовище Node.js, шаблон тестів, V8 і пороги покриття.
- `tsconfig.json` — сувора перевірка типів TypeScript.
- `eslint.config.mjs` — статичний аналіз коду.
- `.prettierrc`, `.prettierignore` — форматування й виключення похідних файлів.
- `.gitignore` — виключення залежностей, покриття, кешу та інших артефактів.
- `package.json`, `package-lock.json` — команди та зафіксовані залежності.

Пороги покриття: рядки — 80 %, гілки — 80 %, функції — 100 %.

## Варіант 2: індекс маси тіла

`src/bmi.ts` містить `calculateBmi(weightKg, heightM)`, а `tests/bmi.test.ts` — 13 тестів цієї функції.

Формула: `weightKg / heightM ** 2`. Вага задається в кілограмах, зріст — у метрах.
Наприклад, `calculateBmi(70, 1.7)` повертає приблизно `24.2214532872` кг/м².
Функція не округлює результат; дробові значення в тестах порівнюються через `toBeCloseTo`.

Нульовий, від’ємний, нескінченний зріст і `NaN` спричиняють `INVALID_HEIGHT`.
Додаткова перевірка ваги відхиляє недодатні та нескінченні значення і `NaN` з `INVALID_WEIGHT`.
Межовий тест — зріст `0`, який має бути відхилений.

Загалом: 17 тестів у двох файлах. Покриття обох модулів — 100 % за всіма показниками.
Індивідуальне завдання оформлено в гілці `lab1-variant2`; показовий приклад — у `main`.
